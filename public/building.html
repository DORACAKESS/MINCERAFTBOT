How it works:

  • Upload a build file → it is parsed and stored in your library.
  • Click a build → the required materials appear (with icons + counts).
  • Preview renders the build in 3D so you know exactly what the bot will place.
  • Build picks a mode, an origin (where the build starts), and the bot does the rest.
