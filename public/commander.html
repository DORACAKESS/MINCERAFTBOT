How power levels work

Each level unlocks more of the command list.

L4 Owner

Everything — .bot:start, .bot:stop, .inv:dropall.

L3 High

Most actions — reconnect, drop items, mine, attack. Cannot stop/start the bot.

L2 Medium

Chat + viewing — make the bot .bot:say, see .inv, potion effects.

L1 Low

Read-only — status, health, hunger, XP, position, and .help.

Not listed

Can chat normally, but the bot ignores anything that looks like a command.

Quick Commands

The full in-game command list — click a command to copy it. Only the required level or higher can run it.

.help usage

.help — page 1 of all commands, one per line

.help 2 — next page of the command list (the footer of each page shows how many pages there are and the next one)

.help <category> — list a category's commands (e.g. .help inv)

.help <category> <page> — page N of a category (e.g. .help bot 2)

.help <category> <command> — details of one command (e.g. .help bot reconnect)
